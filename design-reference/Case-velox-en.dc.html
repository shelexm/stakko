CASE 01 · WEB PRODUCT FOR A DETAILING STUDIO

VÉLOX Detailing Studio

A website, online booking, admin panel and Telegram bot for a car detailing studio. Every channel shares one database and one set of booking rules.

Open live demo Code on GitHub Telegram bot
Role
Full-stack development
Scope
Website · Admin panel · Bot
Core
Python · FastAPI · PostgreSQL
Product language
Russian
01

The problem

The studio needed to take bookings from both the website and Telegram, manage staff schedules and services, update site content without a developer — and make sure the same time slot can’t be taken through two different channels.

02

The solution

A single product built on FastAPI and PostgreSQL. The website, admin panel and Telegram bot share one database and one set of booking rules. The architecture supports multiple studios: every booking belongs to its studio.

03

Client-facing website

A responsive studio website: services and prices, before/after work, reviews, gift certificates and contacts. The interface is shown in Russian, the product’s original language.

04

Online booking

  1. 1ServiceChosen from the studio catalogue
  2. 2SpecialistPick who does the work
  3. 3TimeOnly available slots
  4. 4Contact detailsName, phone, car model — optional
  5. ConfirmationBooking number, calendar file and a cancellation page available until the deadline

The website, admin panel and bot validate bookings against the same rules; overlapping slots are additionally guarded by database-level constraints.

05

Admin panel

The studio’s workspace — from schedules and staff workload to site content. Access is split by role.

  • Schedules and staff workload
  • Services, prices and specialists
  • Clients and bookings
  • Site content, media and reviews
  • Settings and staff access
  • Roles: owner, administrator, specialist
  • Client data deletion on request (Russian Federal Law 152-FZ)
  • Daily backups
06

Telegram bot

For clients

  • Book a service
  • “My bookings” section
  • Reschedule or cancel
  • Ask the administrator a question
  • Reminders 24 hours and 2 hours ahead

For the studio

  • New requests arrive in the administrators’ chat
  • “Confirm”, “Assign specialist” and “Decline” buttons

Testing and quality

The pytest suite is split into unit, integration, API and bot tests, with an isolated environment of its own — a separate Docker Compose stack. Code is linted with ruff, and GitHub Actions is set up in the repository.
