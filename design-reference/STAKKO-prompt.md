## 5. RU / EN

- Маршруты `/ru/` и `/en/` с полностью локализованным контентом, включая метаданные, aria-подписи и состояния меню. Языки внутри версии не смешивать.

- `hreflang`, canonical, уникальные title / description / Open Graph для каждой страницы и языка, favicon.

## 6. Анимации, производительность, доступность

- Только `transform` и `opacity`, CSS custom properties, `requestAnimationFrame`. Без Three.js, GSAP и тяжёлых библиотек.
- Появление секций при прокрутке через IntersectionObserver (threshold ≈ 0.12, rise 0.95 с со stagger). Если JS отключён или включён reduced motion, контент виден сразу.
- `prefers-reduced-motion`: отключить всё необязательное — сферу (один статичный кадр), бегущие строки (статичный список), параллакс, магнитные кнопки, hover-сдвиги. Smooth scroll только при `no-preference`.
- На touch-устройствах эффекты для мыши не включаются.
- Без горизонтальной прокрутки на любых ширинах (`overflow-x: clip` на корне).
- Семантика: header / nav / main / section с `aria-labelledby` / footer. Настоящие `<a>` и `<button>`, `aria-label` у кнопок-иконок, видимые focus-состояния, цели нажатия ≥ 44px.
- Изображения AVIF/WebP с размерами и lazy-загрузкой, зарезервированное место (CLS < 0.1). На мобильных минимум blur.
- Проверить ширины 360, 390, 768, 1024, 1440 и больше.
